# 🌡️ Temperature Converter

Task 3 of the OIBSIP Web Development & Designing internship (Level 1).

🔗 **Live Demo:** [jeevithabk123.github.io/OIBSIP/WebDev-L1-TemperatureConverter/](https://jeevithabk123.github.io/OIBSIP/WebDev-L1-TemperatureConverter/)

## 🎯 Objective
An interactive web tool that converts a temperature value between Celsius,
Fahrenheit, and Kelvin, with real-time input validation, matching the
official task checklist.

## ✨ Features
- 🔢 Numeric input field for the temperature value
- 📋 Dropdown unit selector for the input unit (Celsius / Fahrenheit / Kelvin)
- 🌡️ All three converted values shown simultaneously
- 🔘 Convert button that triggers the calculation on click
- 📊 Result display area with correct unit labels
- ⚠️ Input validation: rejects non-numeric or empty input with an error message
- 🧊 Edge case handling: warns if the input is below absolute zero (-273.15°C)
- 🎨 Clean, centred UI with clear labels
- 🔥❄️ Visual thermometer that reflects the converted temperature (fill height and
  color shift from cool to warm)
- 📱 Responsive layout for mobile

## 📁 Files
- `index.html` — structure
- `style.css` — styling
- `script.js` — conversion logic and validation

## 🛠️ Tech
HTML, CSS, JavaScript (Vanilla) — no frameworks or libraries
