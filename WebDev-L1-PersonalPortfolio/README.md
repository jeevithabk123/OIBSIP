# Personal Portfolio

## 📌 Task
OIBSIP Web Development Internship — Level 1, Task 2

## 📝 Objective
A personal portfolio website that showcases my skills, projects, and contact information — my digital résumé.

## 🛠️ Tech Stack
- HTML5
- CSS3

## ✨ Features
- Profile/hero section with name and role
- About Me section
- Skills section displayed as a visual grid
- Projects section with 2 project cards linking to GitHub
- Contact section with email, GitHub, and LinkedIn
- Smooth navigation between sections
- Consistent branding (color scheme, fonts) throughout
- Fully responsive design (works on mobile and desktop)
