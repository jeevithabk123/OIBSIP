# Landing Page

## 📌 Task
OIBSIP Web Development Internship — Level 1, Task 1

## 📝 Objective
A visually polished static landing page built using HTML5 and CSS3.

## 🛠️ Tech Stack
- HTML5
- CSS3

## ✨ Features
- Sticky navigation bar with 3 links (Home, Features, About)
- Hero section with headline, subheadline, and call-to-action button
- Features section with 3 highlighted boxes
- About section
- Footer with contact placeholders
- Fully responsive design (works on mobile and desktop)
- Consistent color palette throughout
