# EduLearn - Online Learning Platform (Landing Page)

## 📌 Task
OIBSIP Web Development Internship — Level 1, Task 1

## 📝 Objective
A visually polished static landing page for an online learning platform, built using HTML5 and CSS3.

## 🛠️ Tech Stack
- HTML5
- CSS3

## ✨ Features
- Sticky navigation bar with 4 links (Home, Courses, About, Contact)
- Hero section with headline, subheadline, and call-to-action button
- Popular Courses section (Web Development, Python, Data Analytics)
- "Why Choose Us" section with 3 highlighted features
- About section describing the platform
- Contact section
- Footer with social media placeholders
- Fully responsive design (works on mobile and desktop)
- Consistent color palette (navy blue + teal) throughout
